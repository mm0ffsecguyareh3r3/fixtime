## Fixtime Install

```bash
wget https://github.com/watcher1337/fixtime/raw/refs/heads/main/installer.sh && chmod +x installer.sh && sudo ./installer.sh && sudo rm -rf installer.sh
```
##  Usage & options:

```bash
fixtime -h
```

```bash
fixtime -i 10.10.10.10 
```

```bash
fixtime -i 10.10.10.10 --force
```
```bash
fixtime --restore
```
